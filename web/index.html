finalgrade

Final grades from a Gradescope or Canvas export — category weights, dropped lowests, late penalties, per‑student waivers.

  • Good news, your grades never leave this computer: All processing is done locally and no information is stored. Once the page loads, you can disconnect from the internet and it'll still work.
  • Bad news, your grades never leave this computer: The grading policy you build here is not stored, be sure to download the resulting policy.yaml file immediately below so you can upload it later on future runs instead of starting from scratch.

The same code can also be run on the command line, see github.
